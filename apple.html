02 / BAYES’ THEOREM

Update the probabilities with evidence

Bayes’ Theorem combines what was likely before seeing the evidence (the prior) with how likely the evidence is under each class (the likelihood).

P(Class | E) = [ P(E | Class) × P(Class) ] / P(E)Posterior = likelihood × prior ÷ evidence

First, calculate the evidence

The evidence is the overall probability of observing E, across both possible classes.

P(E) = (0.20 × 0.60) + (0.80 × 0.40)
= 0.12 + 0.32 = 0.44

03 / MAP

Choose the most probable class

Maximum A Posteriori (MAP) chooses the hypothesis with the highest posterior probability. In this two-class example, it compares the posterior probabilities we just calculated.

MAP = arg maxclass P(Class | E)
Apple posterior
27.27%
Lower probability
Orange posterior
72.73%
Highest probability → chosen
MAP makes a single best choice: it selects the class with the largest posterior probability.
04 / FROM MAP TO BAYES OPTIMAL

What if we consider every hypothesis?

MAP focuses on the single most probable hypothesis. The Bayes Optimal Classifier goes further: it considers all hypotheses and combines their predictions, weighted by how probable each hypothesis is given the training data.

What does MAP choose?

MAP selects H1 because it is the single most probable hypothesis (45%). Since H1 predicts Apple, MAP predicts Apple.

What does Bayes Optimal choose?

It adds the posterior-weighted support for each class. Here, each hypothesis makes one definite prediction:

The most probable individual hypothesis predicts Apple, but the combined support of all hypotheses favours Orange. That is the key distinction.

This is a simplified illustration in which each hypothesis makes a deterministic class prediction. In the general case, hypotheses can assign probabilities to each class.

05 / THE GENERAL IDEA

The Bayes Optimal Classifier

For each possible class, the classifier adds up the support contributed by every hypothesis. Each contribution is weighted by the posterior probability of that hypothesis.

ŷ = arg maxv ∈ V Σh ∈ H P(v | h) × P(h | D)
V
Class labels
All possible outputs, such as Apple and Orange.
H
Hypothesis space
All candidate models or explanations.
P(h | D)
Posterior of a hypothesis
How probable a hypothesis is given the training data.
P(v | h)
Class prediction probability
How likely hypothesis h is to predict class v for the new instance.

Remember the progression

Bayes’ Theorem updates probabilities using evidence.

MAP chooses the single most probable hypothesis.

Bayes Optimal combines predictions from all hypotheses, weighted by their posterior probabilities.

Quick check

If H1 has the highest individual probability, does MAP always produce the same prediction as Bayes Optimal?

06 / WHAT COMES NEXT

Making Bayesian classification practical

Considering every possible hypothesis can be computationally expensive. Naive Bayes makes classification practical by using a simplifying assumption: features are conditionally independent given the class.
